My direction in IT

My IT Direction

Chosen direction

Software Developer

What do you do in this field?

Develop and maintain software applications.

Which skills are important

  • Problem solving
    • Analyzing project requirements
    • Breaking it down into smaller tasks
    • Designing a solution
  • Knowledge of Data Structures and Algorithms (DSA)
  • Knowledge of programming languages
  • Reading (and writing) documentation
  • Collaborating with team members
    • Communication
    • Understanding someone elses code

Example features

  • Software developer
  • Code maintainer
  • Finding and fixing bugs
  • Creating software for embedded systems
  • Contributing to your favorite open-source projects on GitHub

Why does this appeal to me?

Ever since I learned programming in high scool, it became one of my favorite subjects. I loved being able to spend time writing some code that made my life easier. I also enjoy games. Not just playing them, but thinking about the code behind it and trying to understand exactly how the game mechanics are implemented. I even tried making some games of my own, but it's a lot more difficult than it seems. So far I've only been able to recreate some existing games, but one day I will have enough knowledge to be able to make my own original games and applications for different platforms.
