Why IT?

I want to help people by automating boring tasks and simplifying difficult logic.

My Story

I chose ICT because I want to make my own and other peoples lifes easier.

I learned about programming by following the subject Informatica in high school. I loved the feeling of being able to create something using code to improve my own quality of life, spending some time to write an application that ends up saving hours of manual work.

By studying HBO-ICT at HZ University of Applied Sciences, I'm going to learn how to create functional and useful applications for boths desktop PCs and mobile devices.

After my study I will be working as a software developer, prefereably working from home or in a peaceful environment. In my free time I want to contribute to open source communities and create free and open source alternatives to paid software.

I also want to create code libraries that other developers can use to create their own apps more easily, by simplifying the difficult logic.
