ICT Field of Work

At the HZ University of Applied Sciences, there are two study paths for HBO-ICT: Software Engineering (technically oriented) and Applied Data Science & AI (People & organization oriented).

Software Engineering

As a software developer, you are responsible for developing and maintaining software applications. This involves knowledge of data structures, algorithms, reading/writing documentation and being able to work with different programming languages as well as being able to work with and understand someone elses code.

Tasks: (source)

  • Analyzing the project requirements
  • Designing the application blueprint
  • Writing the application source code
  • Performing tests
  • Debugging/tourbleshooting any errors
  • Using version control systems
  • Collaborating with your team members
  • Writing documentation
  • Deploying the (finished) application

Applied Data Science & AI

As a data scientist, you analyze raw data and turn it into useful information. You make predictions and visualizations which help in making important business decisions, or you make suggestion algorithms for apps like Netflix, YouTube or google search. This involves knowledge of statistics and manipulating data.

Tasks: (source)

  • Collecting data
  • Cleaning data
  • Analyzing data
  • Visualizing data
  • Making predictions or decisions based on the results
