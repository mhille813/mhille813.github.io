Why IT?

I found out about IT by following the subject Informatica in high school, this is where I learned the basics of Python. I liked programming so much that I continued using Python during my free time. Recently, I started learning Lua and trying to make small games.

My motivation for following the ICT programme is to improve my programming skills so that when I'm looking for a specific app and it doesn't exist yet, I will be able to create it myself. Another goal I have is to make my own game someday. I want to follow the software developer path and learn how to create apps for both PC and mobile devices. After completing the programme, I want to find a job as a software developer.
